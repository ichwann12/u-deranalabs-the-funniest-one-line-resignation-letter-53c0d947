## The entry

> I resign. I have fired every minute since March, and nobody has ever once said thank you. — The Cron Job

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

Reads `entry.txt` from the repo root and writes the line verbatim to `output.txt` in the output directory. Node 22, stdlib only, no network, no wall clock.
